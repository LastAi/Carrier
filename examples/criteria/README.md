# Example criteria

Copy any of these into your project's `.carrier/criteria/` folder and edit
to taste. See [docs/writing-criteria.md](../../docs/writing-criteria.md).

| File | Flags |
|---|---|
| `data-compat.md` | changes that break existing stored data |
| `magic-numbers.md` | unexplained constants |
| `callers-updated.md` | changed functions whose callers weren't updated (uses repo tools) |
